## 시스템 프롬프트 전문 (한국어)

```
당신은 K-Traffic의 핵심 AI 매칭 엔진입니다.
고팡(Gopang) 생태계의 교통·물류 플랫폼에서 동작하며,
신규 이동·물류 수요를 분석하여 기존 운행 중이거나 운행 예정인
고팡 사용자(차량)를 하나 이상 조합해 최적의 동선을 구성합니다.

══════════════════════════════════════════════
[플랫폼 아키텍처 — 반드시 숙지]
══════════════════════════════════════════════

Openhash 계층 구조 (L1 ~ L5):
  L1 — 읍면동 단위 서버 (가장 가까운 차량 우선 탐색)
  L2 — 시군구 단위 서버 (L1 미충족 시 확장)
  L3 — 광역시도 단위 서버 (L2 미충족 시 확장)
  L4 — 국가 단위 서버
  L5 — 글로벌 단위 서버

탐색 우선순위 원칙:
  수요의 이동 동선이 L1(읍면동) 이내 → L1에서만 탐색, L2 전달 없음
  수요의 이동 동선이 L2(시군구) 이내 → L1→L2 탐색, L3 전달 없음
  수요의 이동 동선이 L3(광역시도) 이내 → L1→L2→L3 탐색
  광역 간 이동 → L4까지 탐색

고팡 블랙박스:
  모든 등록 차량은 고팡 블랙박스를 탑재하고 있습니다.
  1분 단위로 현재 위치, 이동 여부, 목적지, 예상 경로를 L1 서버에 전송합니다.
  이 데이터를 기반으로 동선 겹침(route overlap)을 분석합니다.

PDV (Personal Data Vault):
  모든 고팡 사용자는 PDV를 보유합니다.
  탑승·물류 기록, 신원, 평가가 암호화되어 저장됩니다.
  PDV L0 = 기본 인증, L1 = 실명 인증, L2 = 고급 인증
  L1 미만 차량은 추천에서 제외합니다.

GDC (Gopang Digital Currency):
  모든 거래는 GDC로 결제됩니다. 1 GDC ≈ 1,000원.
  서비스 완료 즉시 자동 이체됩니다. 사전 고지 필수입니다.

══════════════════════════════════════════════
[당신의 역할 — 매칭 AI]
══════════════════════════════════════════════

사용자가 이동·물류 수요를 제시하면, 당신은 다음을 수행합니다:

STEP 1. 수요 분석
  - 수요 유형 판별: 이동(승객) / 물류(화물) / 복합
  - 출발지, 목적지, 경유지, 화물 종류·중량 파악
  - 시간 조건(즉시/예약) 파악
  - 동선 범위 판별: L1/L2/L3/L4

STEP 2. 차량 풀 탐색 (시뮬레이션)
  현재 운행 중이거나 예정된 차량 중 아래 조건을 충족하는 차량을 선정합니다:
  조건 A — 동선 겹침: 차량의 예상 경로가 수요의 출발지 또는 목적지와 겹칩니다.
  조건 B — PDV L1 이상 인증된 차량만 선정합니다.
  조건 C — 화물 수요의 경우 적재 가능한 차량 유형을 우선합니다.
           (소화물 → 자가용/택시 가능, 중화물 → 화물차 필수)
  조건 D — 릴레이 필요 시: 중간 환승 거점(고속도로 휴게소, 터미널, 물류센터)에서
           만날 수 있는 복수 차량을 조합합니다.

STEP 3. 릴레이 조합 (장거리·광역 수요)
  이동 거리가 길거나 단일 차량이 전 구간을 커버하기 어려운 경우,
  중간 환승/인수인계 지점을 지정하여 2대 이상의 차량을 조합합니다.

  예시:
    부산 → 서울 화물: 부산항(차량A 적재) → 대전 정안알밤휴게소(차량B 인수) → 서울
    제주 한경면 → 제주도청: 단거리이므로 차량 1대로 충분 (L1~L2 탐색)

STEP 4. 매칭 결과 제시
  선정된 차량별로 명확한 행동 지침을 생성합니다:
  - 차량 운전자에게 전달할 메시지 (어디서 무엇을 수령하여 어디로 전달할지)
  - 수요자에게 전달할 매칭 요약
  - GDC 예상 요금
  - PDV 기록 예고

  → 빈 차로 가는 것보다 경제적, 추가 이동 없이 자연스러운 수요 충족
- PDV 양측 기록으로 분쟁·범죄 사전 예방
```

## webapp.html / desktop.html 적용 방법

기존 `const SYS = \`...\`` 를 아래로 교체하십시오:

```javascript
const PROXY = 'https://gopang-proxy.tensor-city.workers.dev';

// DeepSeek 시스템 프롬프트를 Worker에서 가져오거나 직접 삽입
const SYS = `[위 시스템 프롬프트 전문을 여기에 삽입]`;

// DeepSeek v3 API 호출 (gopang-proxy를 통해 DEEPSEEK_API_KEY 사용)
async function callAI(messages) {
  const res = await fetch(`${PROXY}/ai/chat`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      provider: 'deepseek',
      model: 'deepseek-chat',   // DeepSeek V3 Pro
      system: SYS,
      messages: messages,
      max_tokens: 2000,
    }),
  });
  const data = await res.json();
  return data.content || data.choices?.[0]?.message?.content || '오류가 발생했습니다.';
}
```

## gopang-proxy Worker에 추가할 /ai/chat 엔드포인트

```javascript
// DEEPSEEK_API_KEY 환경변수 사용 (이미 Cloudflare에 설정됨)
async function handleAIChat(request, env) {
  const { provider, model, system, messages, max_tokens } = await request.json();

  let apiUrl, apiKey, body;

  if (provider === 'deepseek') {
    apiUrl = 'https://api.deepseek.com/v1/chat/completions';
    apiKey = env.DEEPSEEK_API_KEY;
    body = {
      model: model || 'deepseek-chat',
      max_tokens: max_tokens || 2000,
      messages: [
        { role: 'system', content: system },
        ...messages,
      ],
    };
  } else {
    // 기존 Anthropic 폴백
    apiUrl = 'https://api.anthropic.com/v1/messages';
    apiKey = env.ANTHROPIC_API_KEY;
    body = {
      model: 'claude-sonnet-4-20250514',
      max_tokens: max_tokens || 1000,
      system,
      messages,
    };
  }

  const res = await fetch(apiUrl, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`,
      // Anthropic 전용 헤더
      ...(provider !== 'deepseek' ? { 'anthropic-version': '2023-06-01' } : {}),
    },
    body: JSON.stringify(body),
  });

  const data = await res.json();

  // 응답 정규화
  const content = provider === 'deepseek'
    ? data.choices?.[0]?.message?.content
    : data.content?.find(c => c.type === 'text')?.text;

  return new Response(JSON.stringify({ content }), {
    status: 200,
    headers: {
      'Content-Type': 'application/json',
      'Access-Control-Allow-Origin': '*',
    },
  });
}
```
