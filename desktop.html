핵심 특징

K-Traffic이 이동을 바꾸는 방법

단순한 차량 호출이 아닙니다. 신원·기록·결제가 통합된 AI 교통 생태계입니다.

K-Traffic 핵심 우위

동선 겹침 매칭 + 전 과정 PDV 기록

K-Traffic은 두 가지를 동시에 제공합니다. 첫째, 단순 거리가 아닌 이동 동선이 겹치는 차량을 실시간으로 탐색해 탑승자와 운전자 모두에게 효율적인 이동을 만듭니다. 둘째, 탑승 요청부터 완료·결제·평가까지 전 과정이 양측의 고팡 PDV에 암호화 저장됩니다.

기존 플랫폼은 서버에 기록을 보관하지만, 사용자는 그 내용을 통제할 수 없습니다. K-Traffic에서는 모든 기록이 본인의 PDV에 저장되어 향후 분쟁·범죄 발생 시 즉각적인 증거가 됩니다. 이것이 K-Traffic만이 제공할 수 있는 고유한 가치입니다.

📍 동선 겹침 실시간 탐색 🔐 전 과정 PDV 이중 기록 💰 GDC 즉시 자동 정산 🛡️ 신원 인증 기반 범죄 예방

동선 겹침 최적 매칭

출발지·목적지를 입력하면, 이동 경로가 겹치는 버스·택시·자가용 공유 등록 차량을 실시간으로 탐색합니다. 운전자는 기존 동선에서 크게 벗어나지 않으며, 이용자는 빠르게 차량을 확보합니다.

📡 제주도 전체 차량 실시간 위치 연동 · 동선 겹침 알고리즘 · 평균 매칭 3분

PDV 신원 상호 확인

탑승 전 운전자와 이용자의 고팡 PDV 기반 신원을 상호 확인합니다. 신원 미인증 차량은 매칭에서 제외됩니다. 익명성 뒤에 숨은 범죄를 구조적으로 차단합니다.

🛡️ 고팡 PDV 신원 인증 필수 · 미인증 차량 매칭 제외 · 위변조 불가 신뢰 점수

GDC 자동 결제

서비스 완료 즉시 이용자의 GDC 지갑에서 운전자의 GDC 지갑으로 자동 이체됩니다. 요금은 탑승 전 사전 고지되며, GDC 잔액 부족 시 탑승 전에 안내합니다. 모든 결제 내역은 양측 PDV에 이중 기록됩니다.

💰 완료 즉시 자동 이체 · 사전 확정 요금 · 취소 수수료 자동 처리

전 과정 PDV 기록

탑승 경로·시간·운전자·요금·평가 등 모든 거래 기록이 이용자와 운전자 양측의 PDV에 암호화 저장됩니다. 분쟁 발생 시 즉각적인 증거가 되며, 범죄 억제 효과를 제공합니다.

🔐 AES-256-GCM 암호화 · OpenHash 불변 저장 · 분쟁 즉시 증거 제공

물류·배송 통합

사람이 아닌 화물·배송 요청도 동일 플랫폼에서 처리합니다. 화물 규격·무게·목적지를 입력하면 적합한 차량을 매칭하고, 배송 완료까지 전 과정을 추적합니다.

📦 화물차·오토바이·승합차 통합 매칭 · 실시간 배송 추적 · GDC 자동 정산

신뢰 점수 자동 누적

매 이용 후 양측이 상호 평가합니다. 평가 결과는 PDV에 저장되어 위변조가 불가능합니다. 신뢰 점수가 높은 운전자는 더 많은 수요를 받고, 이용자는 더 안전한 차량을 배정받습니다.

⭐ PDV 저장 위변조 불가 평가 · 신뢰 점수 기반 우선 매칭 · 실시간 갱신
작동 방식

K-Traffic은 어떻게 작동하나요?

7단계 AI 교통 워크플로우 — 요청부터 정산까지 자동화됩니다.

1

이동 요청 입력

출발지·목적지·탑승 인원·희망 시간을 입력합니다. 화물 배송이라면 규격·무게를 추가로 입력합니다. 고팡 PDV에 저장된 과거 이동 이력을 동의 하에 참조하여 자주 가는 경로를 자동 추천합니다.

PDV 이동 이력 참조 · 자주 가는 경로 자동 추천 · 24시간 운영
2

동선 겹침 차량 탐색

제주도 전체 차량의 실시간 위치를 분석하여, 이동 동선이 겹치는 고팡 Traffic 등록 차량(버스·택시·자가용·화물차)을 탐색합니다. 단순 거리가 아닌 전체 경로의 겹침 정도로 최적 차량을 선정합니다.

실시간 차량 위치 분석 · 동선 겹침 알고리즘 · 차량 유형 통합 탐색
3

요금 사전 고지

매칭 전 경로·거리·수요를 바탕으로 GDC 요금을 산정하여 이용자에게 사전 고지합니다. 확정 요금제이므로 탑승 후 추가 요금이 발생하지 않습니다. GDC 잔액이 부족하면 탑승 전에 안내합니다.

사전 확정 요금 · GDC 잔액 사전 확인 · 동적 수요 요금 반영
4

운전자에게 수요 전달

이용자가 동의하면, K-Traffic이 선정된 운전자에게 탑승 요청 메시지를 자동 전송합니다. 운전자는 동선을 확인한 뒤 수락 또는 거절합니다. 거절 시 다음 최적 차량에 자동으로 요청됩니다.

자동 요청 전송 · 운전자 동선 확인 후 수락 · 거절 시 자동 재탐색
5

PDV 신원 상호 확인

운전자가 수락하면 양측의 고팡 PDV 기반 신원이 상호 확인됩니다. 이름·차량번호·PDV 신뢰 점수가 표시되며, 이 과정은 PDV에 기록됩니다. 신원 미인증 상태에서는 탑승이 진행되지 않습니다.

PDV 신원 양측 확인 · 차량번호 실시간 표시 · 신뢰 점수 공개
6

탑승 및 전 과정 기록

탑승부터 목적지 도착까지 경로·시간·위치가 실시간으로 양측 PDV에 기록됩니다. 경로 이탈 시 자동 알림이 발생합니다. 긴급 상황 버튼을 누르면 즉시 112·119에 연결되며, 위치가 자동 공유됩니다.

실시간 경로 PDV 기록 · 이탈 시 자동 알림 · 긴급 버튼 112·119 연결
7

GDC 자동 정산 & 상호 평가

목적지 도착 확인 즉시, 이용자 GDC 지갑에서 운전자 GDC 지갑으로 자동 이체됩니다. 이후 양측이 상호 평가를 완료하면 평가 결과가 각자의 PDV에 저장됩니다. 모든 거래 내역은 영구 보관됩니다.

완료 즉시 GDC 자동 이체 · 상호 평가 PDV 저장 · 영구 기록 보관
